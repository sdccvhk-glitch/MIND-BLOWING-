# MindBlow — Android Game Starter

A native Kotlin Android prototype based on the approved MindBlow neon/calm visual concept.

## Included
- Splash + onboarding
- Home dashboard
- Mode selection
- Puzzle mode prototype
- Memory mode prototype
- Focus mode prototype
- Relax mode
- Daily Challenge
- Profile / XP / streak display
- Offline local progress storage
- No login or account required
- Portrait-first UI

## Build
Open this folder in Android Studio, let Gradle sync, then choose **Build > Build App Bundle(s) / APK(s) > Build APK(s)**.

If Android Studio asks for an SDK, install Android SDK Platform 35 and Build Tools through SDK Manager.

Package: `com.mindblow.app`
Version: `1.0`
